# Dashboard de Análisis de Ventas | Tienda Online

## Descripción

Dashboard interactivo desarrollado en **Looker Studio** para analizar el desempeño de ventas de una tienda online. Permite visualizar los ingresos, los pedidos, las unidades vendidas, la distribución de ventas por categoría y el comportamiento de los ingresos por ciudad y a lo largo del tiempo.

## Objetivo

Transformar los datos de ventas en información visual que facilite la identificación de patrones, la comparación de resultados y la toma de decisiones de negocio.

## Herramientas utilizadas

- **Looker Studio:** creación del dashboard y visualización de indicadores.
- **CSV:** fuente de datos para alimentar las visualizaciones.
- **Preparación de datos:** limpieza y transformación de los datos antes del análisis.

## Indicadores principales (KPIs)

- **Ingresos por ventas:** importe total de las ventas consideradas en el análisis.
- **Pedidos realizados:** número de pedidos únicos incluidos en el análisis.
- **Ticket promedio:** ingreso promedio por pedido.
- **Unidades vendidas:** cantidad total de productos vendidos.

Para los indicadores de ventas se consideran los pedidos con estado **Entregado** y **Enviado**, excluyendo los pedidos cancelados, pendientes o sin estado confirmado.

## Visualizaciones

El dashboard contiene las siguientes visualizaciones:

1. **Distribución de ingresos por categoría:** permite comparar la participación de cada categoría en los ingresos totales
2. **Top 5 productos más vendidos:** identifica los productos con mayor cantidad de unidades vendidas
3. **Ingresos por ciudad:** compara el desempeño de ventas entre las ciudades incluidas en los datos
4. **Evolución mensual de ingresos:** muestra el comportamiento de los ingresos a lo largo del tiempo

## Valor del análisis

Este dashboard facilita:

- Identificar las categorías que generan una mayor proporción de ingresos
- Reconocer los productos con mayor volumen de ventas
- Comparar el desempeño comercial entre ciudades
- Observar tendencias mensuales en los ingresos
- Consultar los principales indicadores de forma rápida y visual
