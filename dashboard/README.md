# Dashboard de ventas

## Objetivo
Crear un dashboard interactivo que permita visualizar y comprender el comportamiento de las ventas de una tienda online ficticia

## Herramienta
Looker Studio 

## Indicadores previstos
- Ingreso total de las ventas
- Cantidad de pedidos que cuentan como venta
- Ticket promedio por pedido
- Ingresos por mes
- Productos más vendidos
- Ingresos por categoría
- Distribución de pedidos por estado

## Fuente de datos
Los datos provienen de las tablas de clientes, productos, pedidos y detalle de pedidos, preparadas durante las etapas de limpieza en Excel y análisis en SQL
