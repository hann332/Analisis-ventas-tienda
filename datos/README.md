# Datos del proyecto

## Descripción
Esta carpeta contiene los conjuntos de datos utilizados en el proyecto de análisis de ventas de una tienda online ficticia

## Archivos de datos

| Archivo | Descripción |
|---|---|
| `clientes_limpio.csv` | Información de los clientes, como identificador, nombre, correo electrónico, ciudad y fecha de registro |
| `productos.csv` | Catálogo de productos, categorías y precios |
| `pedidos_Limpio.csv` | Pedidos registrados y su estado |
| `detalle_pedidos.csv` | Productos incluidos en cada pedido, cantidades y precios unitarios |

## Limpieza de datos
Los archivos de clientes y pedidos se trabajaron en Excel para identificar duplicados, estandarizar datos y revisar valores faltantes

Los archivos de productos y detalle de pedidos se utilizan en su versión original

## Consideraciones
- Los datos pertenecen a un ejercicio de práctica con información ficticia
- Los archivos limpios se utilizarán en el análisis con SQL
- Los valores faltantes no se interpretan como información confirmada

## Herramientas
- Microsoft Excel 365
- SQLite
