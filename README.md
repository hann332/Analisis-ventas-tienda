# 📊 Análisis de ventas de una tienda online

**Proyecto de análisis de datos | Portafolio de Data Analyst Jr.**

## Descripción
Análisis de las ventas de una tienda online ficticia para identificar
qué productos, categorías y meses generan más ingresos, y cómo se
comportan los clientes. El flujo de trabajo va de la limpieza en Excel,
a las consultas en SQL, hasta un dashboard final.

## Preguntas que responde el análisis
- ¿Cuánto se vende por mes y cuándo hay picos?
- ¿Cuáles son los 5 productos más vendidos?
- ¿Qué categoría genera más ingresos?
- ¿Cuál es el ticket promedio por pedido?
- ¿Qué clientes compran con más frecuencia y cuáles nunca compraron?

## Herramientas
| Herramienta | Uso |
|---|---|
| Excel | Limpieza de datos y tabla dinámica exploratoria |
| SQL | Consultas para responder las preguntas de negocio |
| Looker Studio / Power BI | Dashboard con KPIs y gráficos |
| GitHub | Documentación y publicación |

## Metodología
1. **Limpieza (Excel):** duplicados, valores vacíos y formatos inconsistentes.
2. **Consultas (SQL):** JOINs, agregaciones y KPIs.
3. **Visualización:** dashboard con filtros por categoría y fecha.
4. **Conclusiones:** hallazgos y recomendaciones.
