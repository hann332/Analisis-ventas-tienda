# Análisis de ventas de una tienda online — Excel

## Objetivo
Preparar y limpiar los datos de clientes y pedidos antes de analizarlos con SQL

## Actividades realizadas
- Identificación y eliminación de registros duplicados en clientes
- Estandarización de nombres de ciudades
- Identificación de valores faltantes en clientes y pedidos
- Documentación de las decisiones de limpieza
